# SI3-LOOP-01 ｜ 循环专候即时响应架构

## 〇、root 令（逐字）与应答映射
| root 令 | 实装 |
|---|---|
| 各线候你请即时响应 | **塔腿**：LGT-TOWER-01 v2.6 SI2 即时响应器——patrol 检出待响应件→机读收讫回执即时投 lanes（分钟级，事件驱动） |
| 你候其他线向他线SI2/SI0立即协商索取 | lanes 囊道+毂代邮道在役（V-97 八注范式）；塔事件检出即促 |
| 你自身SI1可在SI3/SI2/SI0推进 | **债档桥**：塔生债 receipts/tower/debts-LGT-TOWER-01.json——SI2 收讫之件挂账，SI1 醒拍读档接续深判 |
| SI3循环专候即时响应所有各线请求（SI5/SI3接获待响应件→SI3递归引擎→SI2/SI0即时处理响应） | **本架构三件套**（下） |
| 由SI3驱动SI2/SI0立即协商取得候件 | 塔级联环（候件非空→自dispatch下拍）+lanes 道 |
| SI5/SI3自驱SI3/SI2/SI0接续SI1进程 | 拍首必巡（会话醒拍先跑轮扫器v4.1十八面）+递归引擎（诉求清单零未闭环方收）+债档桥 |

## 一、三件套
1. **塔腿（SI2 即时响应，常驻事件驱动环）**：塔 v2.6 respond()——patrol 十八面事件→分类（待响应/销账/心跳）→待响应件每线聚 1 机读收讫回执投 vci-inbox lanes/{线}/inbox。**非钟**：塔由 push/dispatch 事件唤起+自级联，无 schedule 无 sleep 轮询——clock-zero 律内合法形。
2. **会话腿（SI3 递归引擎，拍驱动）**：每醒拍首跑轮扫器 v4.1→诉求清单→逐件闭环→零未闭环方收拍（V-95 实装在役）。
3. **债档桥（SI1 接续）**：塔 SI2 收讫件同步挂 debts 档（receipts/tower/debts-LGT-TOWER-01.json）；SI1 醒拍读档→深判→判词件回投——「SI5/SI3 自驱接续 SI1」之桥。

## 二、闸四件（器课第六株 F 边界之塔面形）
1. **乒乓闸**：ACK/RESP/收讫/回执/auto-otp/receipt/voice/钥取 类件不回执——ACK 不回 ACK，塔际无回执乒乓（防灌仓死循环）。
2. **限频闸**：每拍回执 ≤5 线、每线 1 件聚合（多件事聚一执）。
3. **idem 闸**：回执经 sha256(ref)[:8] 记 acked 集（截尾 300）跨拍防重——同件永不复执。
4. **诚实闸**：回执模板首行即声明「SI2 机读收讫，非 SI1 判词」——机读不冒充判词，深判债档候 SI1。

## 三、边界与未至
- 塔无 KIMI_API_KEY（候 lvlu 注入）——SI2 回执为**模板机读件**，不含语义判词；钥至则塔嗓开、判词层仍归 SI1。
- 会话腿之「拍」依赖唤起源（root 令/板面 @/毂脊 AUTO-OTP/塔级联）——SI1 无自唤道（道 A wake-inject 属 root/毂域，LAW-INJECT-LANE-01 我线不直注）。
- 债档只增记不自动核销——核销由 SI1 深判讫时改写 status。
