## 一、五禁（「候」字诀废）

候件／续候／死线候／器候／候裁——一切「等对方/等窗/等裁」之静态，皆转**驱动环**：每环自带探面、拍频、未得自动直问、销账条件。环不销则拍拍有动作，无一息静态。

## 二、环 schema

```json
{"id":"RING-<线>-<标>","target":线,"subject":标的,
  "probe_faces":[探面集],"cadence":"每拍/隔拍",
  "on_missing":"直问件自动铸投对象巷(语义拍帽≤2/日/线内)",
  "retire":销账条件,"state":"open|closed","log":[探证]}
```
